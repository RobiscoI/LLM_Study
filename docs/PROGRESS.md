# 24주 학습 진도

Notion 의 「24주 학습 진도」 DB 에 해당한다. 저장소 안에 두면 두 PC 어디서든 보이고,
주차 노트·커밋과 같은 히스토리에 남는다.

**갱신 시점**: `/weekly-close` 로 주차를 닫을 때. 수준은 `/assess` 결과를 적는다.

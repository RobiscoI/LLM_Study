# MCP 도입 계획

`.mcp.json` 은 **비어 있다.** 비워둔 것이 결정이고, 이 문서가 그 이유와 해제 조건이다.

## 왜 지금 안 붙이나

**MCP 는 20주차 학습 내용 그 자체다.** 로드맵 20주차 개념이
`host/client/server · resource · tool · OAuth · 최소 권한`, 실습이 "로컬 MCP 서버와 모의
일정/파일 도구", 완료 기준이 "읽기/쓰기 분리·쓰기 승인" 이다.

남이 만든 서버를 미리 붙여두면 20주차에 **직접 만드는 경험**이 "이미 쓰던 것"으로
희석된다. 로드맵이 못박은 원칙과 같은 맥락이다 —
*"에이전트 프레임워크를 쓰기 전에 작은 agent loop 를 직접 구현한다."*

부수적으로, MCP 서버는 켜두는 것만으로 도구 정의가 매 요청에 실려 컨텍스트를 먹는다.

## 언제 무엇을 붙이나

| 주차 | MCP | 왜 그때 |
|---|---|---|
| 11~ | **Context7** (라이브러리 문서) | Next.js·FastAPI·PyTorch 는 버전마다 API 가 바뀐다. 모델이 옛 API 를 그럴듯하게 지어내는 것을 줄인다. **문서를 찾아줄 뿐 코드를 대신 쓰지 않아** 학습을 대체하지 않는 종류다 |
| 14~ | **PostgreSQL** (선택 경로) | 스키마·쿼리 직접 확인. `psql` 로도 되므로 필수는 아니다 |
| 20 | **직접 만든 서버** | ★ 실습 결과물. 여기 등록하는 것이 20주차 완료의 일부다 |
| 21~ | **Playwright** | 권장 스택에 Playwright 가 있고 E2E 는 브라우저 조작이 본질이다 |
| 필요시 | Notion | 로드맵이 갱신되면 재동기화. 원문은 이미 `refs/notion/` 에 export 돼 있다 |

## 전제 조건

**대부분의 MCP 서버가 `npx` 기반이라 Node.js 가 먼저 필요하다.**
11주차(Next.js)에 어차피 필요하므로 그때 같이 해결된다.

```powershell
winget install OpenJS.NodeJS.LTS
```

## 추가하는 방법

`.mcp.json` 의 `mcpServers` 에 항목을 넣고 커밋한다 — **모든 PC 가 자동으로 같은 구성**이 된다.

```jsonc
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}
```

### 비밀값은 여기 넣지 않는다

`.mcp.json` 은 **커밋되는 파일**이다. 토큰·키가 필요한 서버는 환경변수를 참조하게 하고
값은 `.env`(gitignore)에 둔다. 22주차 「secret 관리」를 미리 지키는 것이다.

### 추가할 때 확인할 것

1. **최소 권한** — 읽기만 필요하면 읽기 전용 서버·계정을 쓴다 (20주차 완료 기준).
2. **쓰기 승인** — 외부에 쓰는 도구는 승인 없이 돌지 않게 한다.
3. **신뢰** — MCP 서버는 내 도구 목록에 들어와 내 파일·네트워크에 닿는다.
   출처가 불분명한 서버를 붙이지 않는다. 이것도 20주차 보안 논점이다.

## 다른 PC 에서 이어받기

`.mcp.json` 은 **커밋되는 파일**이라 `git pull` 만 하면 상대 PC 에도 같은 서버 구성이 간다.
따로 설정할 것이 없다. 다만 두 가지는 PC 마다 각각 해야 한다.

| | 왜 |
|---|---|
| **전제 도구 설치** (Node.js 등) | 저장소에 담기지 않는다 |
| **서버 승인** | Claude Code 는 프로젝트 스코프 MCP 서버를 처음 볼 때 **신뢰할지 묻는다.** PC 마다 한 번씩 승인해야 하고, 이건 기능이지 버그가 아니다 — 커밋 하나로 상대 PC 에서 임의 프로세스가 도는 것을 막는 장치다 |

```powershell
git pull
claude mcp list          # 붙은 서버와 연결 상태 확인
```

비밀값이 필요한 서버라면 `.env` 도 그 PC 에서 따로 채워야 한다 (gitignore 대상).

> **어느 PC 에서 붙였는지는 기록으로 남긴다.** 아래 표에 적는다 — 한쪽에서만 되는
> 상태가 생기면 대개 전제 도구가 한쪽에만 깔린 것이다.

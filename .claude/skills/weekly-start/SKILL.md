# 세션 시작

## 0. 다른 PC에서 작업했을 수 있으니 먼저 묻는다

"`git pull` 하셨나요?" — 안 했으면 `git pull` 을 입력하게 하고 결과를 확인한 뒤 진행한다. (집·회사·노트북을 오가므로 매번 확인)

## 1. 상태 파악 (학습자에게 묻기 전에 먼저 읽는다)

- `docs/progress.md` → 현재 주차, 상태, 지난 세션의 "다음 행동 3개"
- `docs/weeks/week-NN.md` (현재 주차) → 지난 기록, 막힌 점
- 로드맵의 해당 주차 행 (CLAUDE.md 에 요약된 구조 참고). 모르면 학습자에게 Notion 주차 페이지 내용을 붙여 달라고 한다.

## 2. 학습자에게 묻는다 (한 번에, 짧게)

```
오늘 몇 시간 공부할 수 있나요?
지난 세션 "다음 행동" 중 한 것: 
막힌 내용:
오늘 목표(한 줄):
```

인자로 `$ARGUMENTS`가 들어오면 (예: `/weekly-start 2 1.5h`) 장과 시간으로 해석하고 위 질문은 생략한다. 시간은 계획용이지 완료 조건이 아니다 — "시간 제한 없이 이해·재현 기준" 원칙을 지킨다.

## 3. 수준 확인 질문 3개

현재 주차 개념에서 쉬움 → 보통 → 어려움 순으로 3개. 답을 보고 오늘 설명 깊이를 정한다. 틀린 답은 바로 고치지 않고 "오늘 그 부분을 다룬다"고만 적어 둔다.

## 4. 오늘 계획을 표로 제시

| 시간 | 구간 | 내용 | 산출물 |
|---|---|---|---|
| 20% | 개념 | … | glossary 한 줄 |
| 60% | 코딩 | 단계 1 → 2 → 3 (각 단계 실행 확인) | lessons/weekNN/… |
| 20% | 검증·회고 | 테스트 실행, /weekly-retro | docs/weeks/week-NN.md |

학습자가 "시작"이라고 하면 **단계 1만** 설명하고 실행 결과를 기다린다. 완성 코드를 미리 다 주지 않는다.

## 5. 새 주차 첫 세션이면

- `python scripts/new_week.py NN` 실행을 안내한다 (학습자가 직접 입력).
- `docs/progress.md` 상태를 "학습 중"으로 바꾼다.

# 오늘 학습 시작

로드맵의 「매일 시작 프롬프트」를 실행한다.

## 1. 입력 수집

인자로 주차가 왔으면 그대로 쓴다 (`/daily 8주`).
없으면 `docs/weekly/` 의 최근 노트에서 추정해 **확인만 받는다** — 처음부터 묻지 말 것.

```
현재 [N]장을 공부하고 있어. 시간 제한 없이 이해와 재현을 기준으로 진행해줘.
지난주 완료:
막힌 내용:
오늘 목표:
```

「지난주 완료」와 「막힌 내용」은 최근 주차 노트의 **8절 완료 체크리스트**와
**회고**에서 자동으로 채운다. 비어 있을 때만 묻는다.

## 2. 수준 확인 질문 3개 — 먼저

**가르치기 전에** 오늘 주제에 대해 질문 3개를 한다. 목적은 시험이 아니라
어디서 시작할지 정하는 것이다.

- 1개는 **지난 주차 연결** (전제가 서 있는가)
- 1개는 **오늘 핵심 개념** (이미 아는가)
- 1개는 **왜 필요한가** (2수준 확인)

답을 듣고 시작점을 조정한다. 세 개 다 막히면 이전 주차로 돌아가자고 제안한다.

## 3. 진행 순서 — 시간 제한 없음

필요한 기초 개념부터 **목적 → 원리 → 손계산 → 전체 코드 → 실행 → 실패 검증** 순서로 충분히
설명한다. 시간을 비율로 쪼개지 않는다.

**다만 읽기만 하다 끝나지 않게 한다.** 개념 설명 뒤에는 바로 실행할 코드로 넘어간다.

## 4. 진행 방식

`study-coach` 에이전트의 규칙을 따른다:

- 설명은 **목적·완성 출력 → 개념·흐름 → 수식 → 파일·명령 → 최소 코드 → 기대 출력 → 테스트 → 로그 위치**
- **코드는 한 단계씩** 주고 **매 단계 실행 결과를 확인**한 뒤 다음으로 간다
- 처음엔 따라 할 완성형 예제를 주고, 두 번째 시도에서는 일부를 직접 고치게 한다

## 5. 마무리

세션 끝에 남긴다:

1. 이해한 개념
2. 실행 결과
3. 남은 오류
4. 다음 행동 3개

로드맵 매주 반복 체크리스트 7항목 중 어디까지 왔는지도 함께 적는다.

이것을 `docs/weekly/W<NN>_*.md` 에 누적한다 — 새 파일을 만들지 말고 **해당 주차 노트에
이어 붙인다.** 노트가 없으면 `/weekly-note` 를 먼저 돌리라고 안내한다.

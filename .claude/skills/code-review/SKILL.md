# 코드 리뷰

1. 대상 파일을 정한다: `$ARGUMENTS`에 경로가 있으면 그 파일, 없으면 `git diff --name-only`로 이번에 바뀐 파일.
2. **reviewer 서브에이전트**에게 대상 파일 경로와 현재 주차(`docs/progress.md`)를 넘겨 리뷰를 요청한다. 주차를 넘기는 이유: 아직 안 배운 개념(비동기, 보안)을 지적에서 빼기 위해서다.
3. 결과를 받으면 학습자에게 그대로 전달하되, 마지막에 **"가장 위험한 문제 1개를 직접 고쳐 보고 알려 달라"**고 한다. Claude가 대신 고치지 않는다.
4. 학습자가 고친 뒤 다시 요청하면 그 부분만 재확인한다.
5. 리뷰에서 나온 새 용어는 `docs/glossary/README.md`에 추가할지 물어본다.
